# Project brief

## Purpose

Create a reusable Omarchy theme celebrating Nigerian Independence Day, with a blog post introducing the design and explaining how readers can install it.

## First version

- Green and white identity, with deep green backgrounds for comfortable daily use.
- Clear text, visible focus states, and distinct terminal status colours.
- Twenty real, high-resolution Nigerian photographs, each credited on the desktop, the lock screen and CREDITS.md.
- Original image files, traceable sources, and redistribution credits.
- One theme repository with a palette, backgrounds, installation instructions, and blog draft.

## Before the public launch

- Review the theme on a running Omarchy desktop, including terminal, launcher, bar, and notifications.
- Check both wallpaper crops on the intended monitor sizes.
- Capture a real desktop screenshot for the README and article.
- Publish the repository and verify installation from its actual URL on another Omarchy setup.
- Replace the blog draft's release placeholders and add the tested Omarchy version.

## Possible later additions

A light variant, more cities such as Ibadan, Kano, Enugu, and Port Harcourt, and community photo contributions with explicit reuse permissions. Prioritise landscape originals at least 3840 × 2160 for future 4K wallpapers.
